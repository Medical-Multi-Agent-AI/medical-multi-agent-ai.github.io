# medical-multi-agent-ai.github.io
Official website of the Medical Multi-Agent AI Laboratory (MMAI).

## Website

The lab website contains three independent English pages:

- Research: `index.html` — paper figures, bibliographic information, Citation and Details.
- Data: `data.html` — data resources.
- Code: `code.html` — code repositories.

The shared styles and citation interaction are in `assets/site.css` and `assets/site.js`. Images are kept in `assets/`; BibTeX files are in `citations/`. There is no build step or package installation.

For local preview, serve this folder with a static HTTP server. GitHub Pages publishes the `main` branch from the repository root. The empty `.nojekyll` file keeps the site static.

The existing TriPAH project page is linked by its absolute URL and is managed by its own project repository.
